# Invest AI — Multi-Agent Conversational Guidance Platform

Invest AI is a production multi-agent conversational AI platform I architected and built on Google's Agent Development Kit (ADK), FastAPI, and Google Cloud, delivering compliant, guardrailed investment and financial-wellbeing guidance to customers of a regulated financial services organization. Rather than relying on a single LLM prompt, the system routes every customer message through an orchestrated pipeline of 15+ specialized agents — intent classification, input/output guardrails, knowledge retrieval, a deterministic rules engine for sensitive customer journeys, response rewriting, and next-best-action selection — all coordinated through a shared session-state contract so the conversation stays coherent, auditable, and safe.

The platform is deployed on Vertex AI Agent Engine behind FastAPI, with BigQuery used as the system of record for conversation summaries, guardrail outcomes, and audit trails, and Secret Manager managing certificates and credentials for mTLS-secured integrations with backend financial systems. I built the routing logic that prioritizes scenarios (handoffs, stock responses, guidance, targeted support, general knowledge) in strict order, async fan-out clients with retry policies for external data lookups, and a full OpenTelemetry tracing setup exported to GCP Trace and Monitoring for end-to-end observability across the agent pipeline.

To keep a safety-critical, regulated product reliable, I established a six-tier automated testing strategy (unit, integration, end-to-end, performance, mutation, and deployment tests) with an enforced coverage gate in CI, plus persona-based conversation simulation and a Pegasus-based evaluation framework that scores RAG quality, summarization accuracy, and escalation handling before every release. The result is an AI system where business-critical logic — not just model prompting — drives correctness, which reduced manual advisor workload on routine queries while keeping full auditability for compliance.

**Tech stack:** Google ADK, google-genai, LiteLLM, FastAPI, Vertex AI Agent Engine, BigQuery, Secret Manager, OpenTelemetry, Docker, Kubernetes, Helm, Harness CI/CD, pytest, Pegasus Evaluation Framework.
