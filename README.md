# Portfolio

React + Vite portfolio for Sri Sai Akhil Edupalli.

## Scripts

- `npm install` — install dependencies
- `npm run dev` — start the dev server
- `npm run build` — production build into `dist/`
- `npm run preview` — preview the production build

## Structure

- `src/components/` — UI components, one per page section
- `src/data/` — content (skills, projects, experience, site info)
- `src/hooks/` — reusable hooks
- `src/styles/` — global CSS
- `docs/` — resume PDF and project write-up
